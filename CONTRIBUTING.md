# Como contribuir

Obrigado por considerar contribuir com o projeto Administração Tech.

Este projeto é uma trilha autodidata aberta sobre Administração Digital, Automação e Inteligência Artificial. A prioridade é manter o material claro, acessível, prático e útil para iniciantes.

## Formas de contribuir

Você pode contribuir:

- corrigindo erros de escrita ou links quebrados;
- sugerindo novos módulos;
- melhorando explicações;
- adicionando atividades práticas;
- indicando ferramentas;
- sugerindo referências confiáveis;
- revisando acessibilidade e clareza;
- compartilhando estudos de caso.

## Antes de enviar

Antes de abrir um Pull Request:

1. Verifique se já existe uma Issue parecida.
2. Prefira mudanças pequenas e bem explicadas.
3. Use linguagem simples.
4. Evite jargões sem explicação.
5. Inclua fonte quando adicionar referência externa.
6. Revise links internos.

## Padrão de texto

O material deve ser:

- claro;
- direto;
- inclusivo;
- prático;
- verificável;
- amigável para iniciantes.

Evite:

- promessas exageradas;
- conteúdo copiado sem permissão;
- links sem contexto;
- recomendações pagas sem aviso;
- uso de IA sem revisão humana.

## Como abrir uma Issue

Use os modelos disponíveis em `.github/ISSUE_TEMPLATE/` para:

- sugerir um módulo;
- corrigir conteúdo;
- indicar ferramenta ou referência;
- propor projeto prático.

Explique o problema ou sugestão com contexto suficiente para outra pessoa entender.

## Como enviar um Pull Request

Ao abrir um Pull Request:

- descreva o que foi alterado;
- explique por que a mudança é útil;
- indique quais arquivos foram modificados;
- confirme se os links internos funcionam;
- informe se a mudança veio de uma Issue.

## Licença das contribuições

Ao contribuir, você concorda que sua contribuição de conteúdo educacional será publicada sob a licença Creative Commons Attribution 4.0 International.

Se no futuro houver código neste repositório, a licença aplicável ao código será indicada separadamente.
