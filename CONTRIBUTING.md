# Como Contribuir

Obrigado por considerar contribuir com o Administracao Tech.

Este projeto e uma trilha autodidata aberta sobre Administracao Digital, Automacao e Inteligencia Artificial. A prioridade e manter o material claro, acessivel, pratico e util para iniciantes.

## Formas De Contribuir

Voce pode contribuir:

- corrigindo erros de escrita ou links quebrados;
- sugerindo novos modulos;
- melhorando explicacoes;
- adicionando atividades praticas;
- indicando ferramentas;
- sugerindo referencias confiaveis;
- revisando acessibilidade e clareza;
- compartilhando estudos de caso.

## Antes De Enviar

Antes de abrir um Pull Request:

1. Verifique se ja existe uma Issue parecida.
2. Prefira mudancas pequenas e bem explicadas.
3. Use linguagem simples.
4. Evite jargoes sem explicacao.
5. Inclua fonte quando adicionar referencia externa.
6. Revise links internos.

## Padrao De Texto

O material deve ser:

- claro;
- direto;
- inclusivo;
- pratico;
- verificavel;
- amigavel para iniciantes.

Evite:

- promessas exageradas;
- conteudo copiado sem permissao;
- links sem contexto;
- recomendacoes pagas sem aviso;
- uso de IA sem revisao humana.

## Como Abrir Uma Issue

Use os modelos disponiveis em `.github/ISSUE_TEMPLATE/` para:

- sugerir um modulo;
- corrigir conteudo;
- indicar ferramenta ou referencia;
- propor projeto pratico.

Explique o problema ou sugestao com contexto suficiente para outra pessoa entender.

## Como Enviar Um Pull Request

Ao abrir um Pull Request:

- descreva o que foi alterado;
- explique por que a mudanca e util;
- indique quais arquivos foram modificados;
- confirme se os links internos funcionam;
- informe se a mudanca veio de uma Issue.

## Licenca Das Contribuicoes

Ao contribuir, voce concorda que sua contribuicao de conteudo educacional sera publicada sob a licenca Creative Commons Attribution 4.0 International.

Se no futuro houver codigo neste repositorio, a licenca aplicavel ao codigo sera indicada separadamente.
