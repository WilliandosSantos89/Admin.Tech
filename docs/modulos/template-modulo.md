# Template pedagógico oficial de módulo

Use este arquivo para criar os módulos 1–7 da Administração Tech. Pense no template como um roteiro de entrega: pessoas diferentes podem dirigir o conteúdo, mas todas passam pelos mesmos pontos de verificação antes de chegar ao destino.

## Como usar

1. copie o conteúdo a partir de **Início do módulo**;
2. renomeie o arquivo como `modulo-XX-nome-do-modulo.md`;
3. substitua todo texto entre colchetes;
4. remova as orientações de autoria em comentários;
5. confira a [matriz curricular](../08-matriz-curricular.md);
6. aplique o [checklist editorial](../checklist-editorial.md);
7. não publique links, imagens ou afirmações que não tenham sido verificados.

O modelo define a estrutura mínima. Uma seção pode crescer quando o tema exigir, mas não deve ser removida sem justificativa no Pull Request.

## Rubrica de avaliação

<!-- Use critérios observáveis. Segurança e privacidade são condições obrigatórias, não pontos extras. -->

| Critério | Precisa revisar | Adequado | Consistente |
| --- | --- | --- | --- |
| Compreensão | Repete termos sem aplicá-los. | Explica e aplica o conceito principal. | Relaciona conceitos e justifica escolhas. |
| Análise do problema | Parte diretamente para uma ferramenta. | Descreve problema e contexto. | Separa causas, fatos, hipóteses e restrições. |
| Entregável | Está incompleto ou difícil de conferir. | Contém os elementos pedidos. | Pode ser reutilizado e compreendido por outra pessoa. |
| Evidências | Apresenta conclusões sem conferência. | Registra uma verificação básica. | Compara critérios, testes ou dados e reconhece limites. |
| Comunicação | Usa linguagem confusa ou sem contexto. | É claro para o público iniciante. | Organiza texto e elementos visuais com acessibilidade. |

| Mapa visual | Organização → pessoas e papéis → rotina → problema → evidência. |

| Caso brasileiro | Rota Certa: registro e execução de uma solicitação de entrega. |
| Exemplo resolvido | Separar o problema de dados incompletos de uma escolha prematura de ferramenta. |
| Atividade guiada | Mapear pessoas, decisões, canais de informação e resultados da rotina. |
| Desafio | Adaptar o mapa a outra pequena organização brasileira. |
